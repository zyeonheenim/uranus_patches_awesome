# Uranus 玩家补丁合集

给 Uranus（`uranus-imessage`）的五个补丁模块，**从一个原版 Uranus 直接安装，互不依赖，可单独装任意一个**。

每个模块自带一键安装脚本、卸载脚本、说明。**全部经过隐私清理**：不含任何角色名、人设、故事、API key、账号、路径或个人信息；凡是需要"你是谁"的地方，全部在装的时候从你自己的 Uranus 里读取。

---

## 五个模块一览

| 模块 | 解决什么 | 原版可装 | 改服务端 |
|---|---|:---:|:---:|
| **01 日志抽屉** | 角落常驻实时日志，等生成时一眼看清是"在慢慢写"还是"API 断了"；右上角还能**顺手切模型**（聊天/线下/兜底） | ✅ | 是（加一个模型快切接口） |
| **02 唤醒自愈** | 电脑睡醒后 Uranus 网络栈卡死、全线超时 → 自动重启一次 | ✅ | 否（独立定时任务） |
| **03 入站看门狗** | "能发不能收"、控制台不进消息 → 每 60 秒巡检、断了自动重连 | ✅ | 是（加个日志端点） |
| **04 群像舞台** | 线下剧情开局勾选出场角色，现场读单人卡人设，结束自动写群像记忆 | ✅ | 是 |
| **05 线下剧情增强** | 版本留底（重roll/手改可恢复）＋气泡样式＋模型/token 显示＋右缘四钮快速跳转 | ✅ | 是 |

## 怎么装

每个模块一个文件夹，**双击里面的安装脚本**即可：macOS 双击 `安装.command`，Windows 双击 `安装.bat`。想装在非默认位置，设一下 `URANUS_ROOT` 环境变量。

- 建议**一个一个装**，装完一个验证没问题再装下一个。
- 每个模块都能单独卸载（macOS `卸载还原.command` / Windows `卸载还原.bat`），互不影响。
- 装完涉及前端的（01、04、05），记得浏览器 **Cmd+R 强刷**；涉及服务端的（01、03、04、05），改完都要**重启 Uranus**（01 的脚本会改 `server/src/index.js`，装完必须重启）。

### Windows 玩家

**01 / 04 / 05 有 Windows 版，双击 `安装.bat` 就行**（同一份 Node 逻辑，只是入口从 `.command` 换成了 `.bat`）。

| 模块 | Windows | 说明 |
|---|:---:|---|
| 01 日志抽屉 | ✅ | 双击 `01-日志抽屉/安装.bat` |
| 02 唤醒自愈 | — | 靠 launchd + `pmset` 读唤醒记录，且这个坑本身是 macOS 睡醒断网 |
| 03 入站看门狗 | — | 判据是 `uranus.log` 里的连接标记；Windows 版日志只在内存和黑窗口里，不落盘 |
| 04 群像舞台 | ✅ | 双击 `04-群像选角/安装.bat` |
| 05 线下剧情增强 | ✅ | 双击 `05-线下剧情增强/安装.bat`（内部 01 号唤醒自愈会自动跳过） |

装之前先让 Uranus 正常跑起来（双击 Uranus 目录里的 `启动.bat`），并在 `cmd` 里确认 `node -v` 是 20 以上。
装完脚本会自动重启服务（杀掉监听 8787 的 node，再开一个窗口跑启动器）；旧窗口停在「请按任意键继续」是正常的，关掉就行。
浏览器强刷用 `Ctrl+F5`。装在别处：`set URANUS_ROOT=D:\Uranus` 之后再跑 `node install.mjs`。

02 / 03 为什么没有 Windows 版、Windows 常见问题（一闪就没、`npm run build` 失败、路径带 `&`、杀软拦截），白皮书里有一整节讲：打开同目录的 `白皮书.html`，找「在 Windows 上装」。

## 各模块详细说明

进每个文件夹看它的 `README.md`。简单说：

- **01 日志抽屉**：装完角落多一个胶囊按钮，点开是实时日志 + 链路状态。断网/限流立刻变红，不用切到控制台面板。右上角 `模型` 按钮可以给一个角色或全部角色切「聊天 / 线下 / 兜底」模型，不用跳去角色页。
- **02 唤醒自愈**：静默工作。睡醒后若进程比最近一次唤醒还旧，会在 90 秒冷静期后自动重启一次。日志平时空着＝正常。
- **03 入站看门狗**：静默工作。日志在 `Uranus_Imessage/watchdog.log`，修过才会写一行；实时状态可在模块 01 的日志抽屉看 `[看门狗]` 行。
- **04 群像舞台**：角色列表多一张「群像舞台」卡。开线下剧情时勾本场出场的角色；演完自动写记忆。装完记得给这张卡选聊天/离线模型。
- **05 线下剧情增强**：一次装四个功能——重 roll/手改的旧稿能翻能恢复、两侧气泡配色分开调、气泡标题显示用了哪个模型和多少 token、右缘四个圆钮快速跳转（跳顶/跳底/上一条/下一条）。这四个功能改同一页 `offline.jsx` 的不同段落，统一安装器按顺序叠加；也和模块 04 共存（已实测）。

## 隐私与安全声明

- 本合集内**没有任何真实角色名、人设正文、聊天记录、剧情存档、记忆库、API key、账号密码、电话号码或本机路径**。
- 收工/扇出脚本里的集体记忆库标识与舞台卡 id 一致（`role-r-cast-stage`），是通用约定，不绑定任何角色或账号；向量 key 从你自己的配置里读取，不内嵌任何密钥。
- 舞台卡模板的模型槽位**故意留空**，由安装者在自己的控制台里选——不替别人指定模型，也不泄漏任何人用的中转站。
- 群像预设基于 **Uranus 原版出厂预设**改造，随包附带成品；里面只有通用规则，没有任何角色名或个人信息。

---

## 兼容性

- 服务端口默认 `8787`、服务名 `com.uranus.imessage`、Uranus 目录 `~/Uranus_Imessage`——都是原版默认值；装在别处用 `URANUS_ROOT` 指定。
- 补丁用"锚点插入"而非整文件覆盖，在官方原版 1.22.3 和 **1.22.9** 上都逐条实测过（装→卸往返、文件逐字节还原）；升级 Uranus 后重跑安装脚本即可。
- 01 / 04 / 05 的 Windows 支持：Node 脚本跨平台，重启方式按平台分支（macOS `launchctl` / Windows `taskkill` + 重开启动器）。
- 模块 04 的服务端补丁同时兼容 1.22.2 与 1.22.7 两种写法。
