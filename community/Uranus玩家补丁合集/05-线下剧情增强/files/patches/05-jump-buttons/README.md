# 05 · 线下剧情 · 四钮快速跳转 (jump-buttons)

> 依赖：无（可单独装，也能和 02/03/04 叠装）｜基线：Uranus 1.22.3｜改动：1 个文件（`client/src/panels/offline.jsx`）

**一句话**：线下剧情右缘多四个半透明圆钮 —— 跳到最上面、上一条我说的、下一条我说的、跳到最新。长剧情里找某句自己说过的话，不用再一指一指往上划。

---

## 它治什么

Uranus 原版的线下剧情已经支持「往上滚自动补更早的记录」，但只能靠手指一下一下划。剧情长了（几百轮）想回到自己之前说过的某句话，或者想直接看最新一轮，只能划到手酸。

装上之后右缘居中常驻四个圆钮：

```
   ⇤⇤   回到最上面
    ⇡    上一次你的发言
    ⇣    下一次你的发言
   ⇥⇥   跳到最新
```

- 双箭头 = 跳到两端（顶 / 底）
- 单箭头 = 在「你」的发言之间跳，一次一条
- 半透明玻璃质感，不挡正文；鼠标悬停才加深
- 剧情还没开始时不显示

---

## 顺手修的一个坑（WebKit / Safari）

光加按钮在 Safari 上会出问题：点「回到最上面」发起平滑滚动，途中「补更早」的逻辑会写一次 `scrollTop`，WebKit 里这一下会**当场取消滚动动画** —— 页面停在半路，Mac 上的 Chrome 却正常（Blink 会重新瞄准 0 飞完）。

补丁里加了一个 `jumpTop` 标志：回顶进行中，锚回逻辑改成「直接钉在 0」，补几批钉几次，直到补完或用户自己动手（滚轮 / 触摸 / 点「跳到底」）为止。这样 Safari 和 Chrome 行为一致。

---

## 机制（改了哪四处）

| 位置 | 作用 |
|---|---|
| import | 补 4 个箭头图标（`ChevronsUp/Down`、`ChevronUp/Down`） |
| `jumpTop` ref + 锚回 / 触摸监听 | WebKit 回顶修复：回顶途中锚回钉 0、手动操作让位 |
| `jumpEdge` / `jumpUser` 两个回调 | 跳两端 / 在「你」的发言间跳；定位靠消息外层 `data-turn-user` 标记 |
| 右缘四钮 UI + `data-turn-user` 标记 | 按钮本体，以及给 `jumpUser` 用的定位锚 |

### 单箭头为什么这样写（v1.1.7）

两个单箭头踩过两个坑，都在这版修掉：

1. **不用 `scrollIntoView`**：这套页面的滚动容器里它对 ⬆️⬇️ 不生效（而 ⏫⏬ 用的 `scrollTo` 一直正常）。现在四个按钮统一走 `box.scrollTo`，自己算目标在滚动内容里的位置，即时滚过去 —— 顺带也避开了平滑滚动被「补更早」打断的问题。
2. **「下一条」看视口底，不看视口顶**：早先按「视口顶下方第一条」找，把眼前这条也算成下一条，点它几乎不动、再点还是它，卡在第一条跳不下去。现在往下只找**屏幕下方还没看到**的那条；往上只找**屏幕上方已经滚出去**的那条。没有更多了就往下翻一屏，保证每一下都有反馈。

纯前端改动，**不碰服务端、不碰数据**，卸了不会留下任何存档 residue。

## 安装 / 卸载

```bash
node install.mjs --only 05 --run      # 只装四钮跳转
node install.mjs --all --run          # 连 01~05 全装
node uninstall.mjs --run              # 用备份逐字节还原
```

手动打：

```bash
cd /path/to/Uranus_Imessage
patch -p1 < /path/to/patches/05-jump-buttons/05-jump-buttons.patch
cd client && npm run build
```

改完前端要 `npm run build`，浏览器 `Cmd+R` 强刷一次才看到按钮。
