# 05 · 线下剧情增强（版本留底 / 气泡样式 / 模型token / 四钮跳转）

给线下剧情页加四个功能，一次装完（也可单独装其中一个）：

| 编号 | 功能 | 做什么 |
|---|---|---|
| 02 | **版本留底** | 重 roll、手改、删除的旧稿都留一份，气泡上点「历史 N」能翻、点 ⟲ 能恢复 |
| 03 | **气泡样式** | 两侧气泡的底色/边框/文字色/圆角分开调，存服务端 —— 手机上调完电脑一样 |
| 04 | **模型与 token** | 气泡标题写清「哪个服务商 · 模型 ｜↑输入(缓存) ↓输出」，走兜底的那轮也标出来 |
| 05 | **四钮快速跳转** | 右缘四个半透明圆钮：跳顶 / 上一条我说的 / 下一条我说的 / 跳底（含 Safari 回顶修复） |

---

## 怎么装

- **macOS**：双击 `安装.command`，四个功能一次装好。
- **Windows**：双击 `安装.bat`，同样四个功能一次装好（内部 01 号「唤醒自愈」是 macOS 专属，会自动跳过）。
- **只装某一个**：终端里 `cd files`，跑 `node installer.mjs --only 05 --run`（编号填 02/03/04/05）。也可以**组合**，例如 `--only 02,04` = 版本留底 + 模型 token，**不装气泡样式**——装了「气泡样式 + 四钮」插件的玩家就用这个组合。
- **装在非默认位置**：设一下 `URANUS_ROOT=/你的/Uranus路径` 再运行；`URANUS_DIR` 也认。
- **手动 / 只装一个（两个平台一样）**：进 `files` 目录跑 `node installer.mjs --only 05 --run`。

装完改了前端，浏览器强刷一次（`Cmd+R` / `Ctrl+F5`）才看到新按钮/新标题；涉及服务端的要重启 Uranus 才生效。

## 怎么卸

双击 `卸载还原.command`（Windows：`卸载还原.bat`），用装之前那份备份逐字节还原。只动这四个功能改过的源码文件，**不碰角色卡、记忆库、剧情存档**。

---

## 安全设计

- 装之前先把要改的文件备份到 Uranus 目录下的 `.patches-backup-<时间戳>/`。
- 任一补丁对不上（版本差太多 / 文件被大改）就**整份不写**，不会改坏半个文件；确有把握可加 `--force`。
- 装完自动跑 17 项自检（存档读写、留底恢复、样式白名单、用量翻译等），不联网、不碰真实数据。

## 版本与共存

- 补丁按原版 **1.22.3** 源码做，1.22.2 / 1.22.7 实测也能打上。
- 这四个功能改的是同一页 `offline.jsx` 的不同段落，按 02→03→04→05 顺序叠加，统一安装器会自动处理。
- 和本合集的「04 群像舞台」也改这个文件，但锚点不同，**两者可同时装**（已实测）。

## 和插件版的关系（装之前先看）

气泡样式（本模块 03）和四钮跳转（本模块 05）也有**插件版** `uranus-plugin-offline-deco`。**同一个功能只能留一套**——同时装会出现**两排四钮**、两套气泡样式互相覆盖。

| 你装了插件 `offline-deco` 吗 | 本模块怎么装 | 得到 |
|---|---|---|
| 装了 | `--only 02,04` | 版本留底 + 模型 token（不碰气泡样式和四钮）|
| 没装 | `--all` 或双击安装脚本 | 四个功能全齐 |

模型 token（04）**只依赖 02，不依赖 03 气泡样式**——在原版 1.22.9 上只打 02 后逐文件实测过（6 个文件、锚点零偏移），所以上表第一个组合是安全的，安装器也不会再自动把 03 补上。

## 隐私

这一套补丁**不含任何角色名、人设、密钥、账号或个人信息**。`files/` 里的说明文档用「某服务商 · 某模型」作示例占位，不指向任何真实配置；API key、模型都从你自己的 Uranus 配置里读取。
