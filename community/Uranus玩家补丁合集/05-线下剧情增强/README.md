# 05 · 线下剧情增强（版本留底 / 气泡样式 / 模型token / 四钮跳转）

给线下剧情页加四个功能，一次装完（也可单独装其中一个）：

| 编号 | 功能 | 做什么 |
|---|---|---|
| 02 | **版本留底** | 重 roll、手改、删除的旧稿都留一份，气泡上点「历史 N」能翻、点 ⟲ 能恢复 |
| 03 | **气泡样式** | 两侧气泡的底色/边框/文字色/圆角分开调，存服务端 —— 手机上调完电脑一样 |
| 04 | **模型与 token** | 气泡标题写清「哪个服务商 · 模型 ｜↑输入(缓存) ↓输出」，走兜底的那轮也标出来 |
| 05 | **四钮快速跳转** | 右缘四个半透明圆钮：跳顶 / 上一条我说的 / 下一条我说的 / 跳底（含 Safari 回顶修复） |

---

## 怎么装

- **macOS**：双击 `安装.command`，四个功能一次装好。
- **只装某一个**：终端里 `cd files`，跑 `node 安装器.mjs --only 05 --run`（编号填 02/03/04/05）。
- **装在非默认位置**：设一下 `URANUS_ROOT=/你的/Uranus路径` 再运行；`URANUS_DIR` 也认。
- **Windows**：进 `files` 目录用 node 跑上面的命令（01 唤醒自愈那类 launchd 定时任务不适用，这里没有）。

装完改了前端，浏览器 **Cmd+R 强刷**一次才看到新按钮/新标题；涉及服务端的会提示重启 Uranus。

## 怎么卸

双击 `卸载还原.command`，用装之前那份备份逐字节还原。只动这四个功能改过的源码文件，**不碰角色卡、记忆库、剧情存档**。

---

## 安全设计

- 装之前先把要改的文件备份到 Uranus 目录下的 `.patches-backup-<时间戳>/`。
- 任一补丁对不上（版本差太多 / 文件被大改）就**整份不写**，不会改坏半个文件；确有把握可加 `--force`。
- 装完自动跑 17 项自检（存档读写、留底恢复、样式白名单、用量翻译等），不联网、不碰真实数据。

## 版本与共存

- 补丁按原版 **1.22.3** 源码做，1.22.2 / 1.22.7 实测也能打上。
- 这四个功能改的是同一页 `offline.jsx` 的不同段落，按 02→03→04→05 顺序叠加，统一安装器会自动处理。
- 和本合集的「04 群像舞台」也改这个文件，但锚点不同，**两者可同时装**（已实测）。

## 隐私

这一套补丁**不含任何角色名、人设、密钥、账号或个人信息**。`files/` 里的说明文档用「某服务商 · 某模型」作示例占位，不指向任何真实配置；API key、模型都从你自己的 Uranus 配置里读取。
